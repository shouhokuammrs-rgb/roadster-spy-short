# C01 — Vance 主観：右の窓を見上げると、降りてくる（冒頭。本編で使うのは 1.25–4.1 秒＝2.85 秒）

- 視点：Vance 主観（右ハンドル運転席、@VanceGT の中）。前のカットなし（コールドオープン）。次の C02 は「数分前」に戻る
- 参照動画：previs/out/C01_ref.mp4（世界の時間 W22.8–27.8 を Vance の目のカメラで。10/18 レンダー）
- エレメント：@VanceGT（車内・ひび割れた防弾ガラス）／@RoadsterW4（降りてくる白い車）／@CliffRoadDay（崖道）

- ガラス：車内から外を見るカット。白い車は底面と側面だけ（中は見えない高さ）
