## 10/19 グレーボックスを立体に（本人「もっと立体的な図形作れるじゃん？」）

## 10/19 接触と動きを物理的に（本人「オブジェクト同士の接触とか動きとか物理的に自然にして」）

previs/physics_check.py：世界の全時刻（24fps）で、地形へのめり込み・ガードレールの貫通・浮き・車同士/人と車の重なり・足の接地・加速度の跳び・横滑りを調べる。
前（直線補間）は 186 区間に問題。直したあとは「直すもの 0」（残る 53 区間は意図したもの＝ジャンプ・ホバー・噴射・着地の衝撃・ドリフト・煙の中の乗り移り。physics_check.py の INTENDED に理由つき）。

見つかって直したもの：
- **補間**：キーの間を直線で結んでいたので、キーごとに速さが一瞬で変わっていた（168 区間）→ interp.py（単調な 3 次、PCHIP）。キーの時刻・位置はそのまま、速さが途切れない、止まる所でゆっくり、行き過ぎない。最後のキーの後ろに止まったキーを足す
- **クーペ**：前の左角が壁に 12cm めり込んでいた → 25cm 道の側へ（C02 のカメラの狙いも同じだけ）
- **壁を登る車が浮いていた**：崖で 36cm、道の岩壁で 66cm 面から離れていた → タイヤが面に触れる位置
- **壁に乗る瞬間**：鼻先が崖に 0.8m めり込んでから持ち上がっていた → 角度ごとに「どこも壁と地面に入らない、いちばん寄った位置」を計算（尻が地面に触れ、前輪が壁に触れて回る）
- **C10 の壁の手前**：壁と平行に横滑りしながら前が上がっていた → 0.7G 加速・0.9G 減速・半径 2.6m の曲がり（横 1G）で道なりに走って壁に鼻先から。動き出しは逆算で W35.6（Vance が乗った直後）
- **ジャンプ**：踏み切りで 21→11 m/s に落ちていた → 空中は速さそのまま、着地は縁の約 31m 先、着地後のブレーキ距離も速さから
- **追っ手 SUV**：区間のつなぎ目で 2.8→23 m/s に跳んでいた → 発進・追走・ブレーキをなめらかにつないだ
- **ガードレール**：クーペの横に降りるとき角がかすめていた、上の道に上がるとき突き抜けていた → 少し内側・噴射で小さく跳ぶ
- **タイヤが回る**（走った距離÷半径）。スポークで回転が見える
- **岩肌の凹凸が道に 0.9m はみ出していた**（自分で入れたもの）→ 凹凸は壁の奥だけ。いちばん外が元の面
