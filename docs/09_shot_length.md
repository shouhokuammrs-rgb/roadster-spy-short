# 09 カットの長さの根拠（10/18）

「各カットが少し長い気がする。この尺は最適か？」に、感覚ではなく **規則と測った数字** で答えるための記録。
再計算：`previs/voice/temp_voice.py` → `previs/shot_length.py` → `previs/world/build_world.py`（本番の声が入ったら、その長さで同じ手順を回す）。

## 結論

1. **長く感じた主な原因は、カットの長さではなく「止まっている絵」と「声がない」こと。** 前の通し（50.9 秒）を 1 コマずつ測ると、23.0 秒（45%）は画面がほぼ動いていなかった（マネキンがポーズの間で止まる・声なし）。止まっていたのは台詞を待つカット（C10・C14・C18 など）と、人の小さな動きが要るカット（C13a・C14b・C17）。生成では人の動きと声がここを埋める
2. **台詞のあるカットは、逆に足りなかった。** 仮の声で測ると、C03 は 2.7 秒に台詞 4.1 秒、C02 は「あと3発」が途中で切れ、C18 は Vance と Sho の台詞が 0.6 秒重なっていた
3. **動きだけのカットは、すでに速い側。** 動きだけの 10 本は平均 2.5 秒、追跡の 7 本は平均 2.3 秒（アクション映画の平均 4 秒、ボーン・アルティメイタム 約 2 秒の間）
4. **規則で出した最短**：本編 56.4 秒＋黒 1.5 秒＝57.9 秒（前は 50.9＋1.5）。長くなったぶんはほぼ台詞（声の合計 17.4 秒＝本編の 31%）
5. **新しい通し（仮の声入り）でも、画面が止まっているのは 30.1 秒（53%）。** うち 11.9 秒は声が鳴っている。残りは人が呼吸もしないマネキンだから止まって見える所で、生成ではプロンプトで小さな動き（視線・手・息・車の揺れ）を入れる場所（3 役分担の「体の動き」）
6. **これ以上短くするなら、削るのは台詞か台本の「間」。** 動きのカットを詰めると、要点が読めないうちに切れる（下の「短くするなら」）

## 規則（なぜその秒数か）

各カットの使う範囲は、手で決めずに次で出す（`previs/shot_length.py`）。

- IN ＝ 最初の要点（動き・台詞）−「読む時間」
- OUT ＝ max（最後の要点 ＋「後ろ」, 最後の台詞の終わり ＋ 0.15 秒）
- 長さ ＝ (OUT − IN) ÷ 再生速度

| 名前 | 秒 | 使う場面 | 根拠 |
|---|---|---|---|
| 読む時間 new | 0.6 | 初めての場所・初めての視点 | 写真が「何の場面か」を判断するのに約 0.6 秒（Potter 2012）。引きほど・込み入るほど読むのに時間がかかり、実際の映画でも引きのカットほど長い（Cutting） |
| 読む時間 known | 0.4 | 見たことのある場所・視点 | 上と 1 注視の間 |
| 読む時間 cont | 0.25 | 前のカットの動きの続き | 1 回の注視が約 0.25 秒（Potter 2012） |
| 後ろ payoff | 0.5 | そのカットの「オチ」を受け取らせる（白で埋まる、火花、火球、口の端） | 見たものを覚えるには約 0.5 秒の邪魔されない処理時間が要る（Potter 2012） |
| 後ろ flow | 0.1 | 次のカットが動きを引き継ぐ（アクションつなぎ） | 止めない。動きの途中で切るほうがつながって見える |
| 台詞の後 | 0.15 | 声を切らない | 語尾を切らないための最小 |
| 声の長さ | 実測 | 仮の声（OpenJTalk 標準速度）| 間を含めて 4.7〜6.2 モーラ/秒。聞き取りやすい話速 320〜360 モーラ/分（5.3〜6.0/秒）の帯にほぼ入る。本番の声で測り直す |
| 英語字幕 | ≤20 文字/秒、≥5/6 秒 | 表示＝声＋0.3 秒 | Netflix の英語字幕の基準。「……橋がないが」は "...The bridge is out." だと 24 文字/秒で速すぎるので "...No bridge." に |

要点の区間は、グレーボックスを 1/8 秒ごとに測った値（車の画面位置・大きさ、絵の動きの量。`previs/measure_events.py`）とコマ割りから取った。

## リズム（並べたときに速すぎ・遅すぎないか）

| 区間 | カット | 平均の長さ |
|---|---|---|
| 導入（包囲〜到着） | C01–C07 | 3.7 秒 |
| 脱出（煙幕〜壁） | C09–C12 | 3.5 秒 |
| 追跡（上の道〜着地） | C13a–C17 | **2.3 秒** |
| 締め | C18 | 7.5 秒 |

- アクション映画の平均ショット長は約 4 秒（ジャンル別で最短）。ボーンシリーズは 4 → 2.4 → 2 秒。2000 年以降の映画は平均 4 秒未満（Cutting）
- 導入〜脱出はアクション映画の平均並み、追跡はボーン級に速い。**クライマックスに向かって短くなり、最後の会話で長く取る** という台本の設計どおりの形になっている
- 締めの C18 が長いのは、オチの台詞 2 本＋間。ここを短くするとオチが速口になる

## これ以上短くするなら（本人の判断）

動きのカットは規則の下限なので、短くできるのは台詞と台本の「間」。仮の声で測った効き目：

| 案 | 短くなる | 失うもの |
|---|---|---|
| C03 の「ナインから。」を削る（「上の道。あれを使いなさい。」） | 約 1.1 秒 | Chief が Vance の連絡を中継していると分かる手がかり |
| C03 の「上。」をやめ、見上げて「了解。」だけ | 約 0.7 秒 | Sho が自分の目で上を確かめる一拍 |
| C18 の間を 1.0 → 0.6 秒 | 0.4 秒 | オチの前の溜め |
| C10 の間を 1.0 → 0.6 秒 | 0.4 秒 | 「掴まっててくださいね」の後の、何が起きるか分からない一拍 |
| C06b の頂点の一拍 1.2 → 0.6 秒 | 0.6 秒 | 到着の見得（台本の「頂点で無音」） |
| C02 の「本部。」を削る | ほぼ 0 | （C02 はマガジンの動きで長さが決まっているので縮まない） |
