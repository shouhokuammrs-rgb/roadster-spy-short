## フォルダ

```
animatic/   HTML Canvas の絵コンテ（54秒、クレジット0で全体を確認する）
previs/     Blender(bpy) グレーボックス。座標でシーンを配置してレンダー
prompts/    カットごとの Seedance プロンプト（英語）。通った版だけ置く
assets/     エレメント画像（車など）
tests/      生成テストのコマ割りと所見（C12/ など）
docs/       上記ドキュメント
```

## 運用ルール

- 新しい学び・判断は **その日のうちに** docs に書く（チャットの文脈はいずれ消える）
- プロンプトは「通った版」を prompts/ に、失敗版は tests/ の所見に残す
- クレジットを使ったら docs/05_log.md に 1 行
